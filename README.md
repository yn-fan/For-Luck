# 佛了 · For Luck

一个移动优先的原创网页仪式玩具：跟随节拍在八种仪式主题间切换，积攒功德或向无边海中放生鱼儿。

## 功能

- 取消顶部木鱼 / 放生标签，把所有玩法统一为八款主题：玄木共鸣、青团捣捣、盘珠子、开门啊我知道你在家、敲张照片、灯具开关、上柱香和放生
- 主题轮盘位于顶栏 Logo 右侧，不再覆盖古门或舞台主体
- 每轮开始前可全屏左右滑动，或使用上一个 / 下一个按钮选择起始主题；进入本轮后关闭手动选择
- 主题切换采用旧主题滑出、新主题从相反方向滑入的 480ms 横向过场；减少动态时直接切换
- 进入本轮后每 2 个八拍自动随机切换主题；照片尚未上传时，自动轮换只使用其他七款
- 八款主题分别使用共鸣波纹、艾草春色、念珠光环、古宅院墙、相片画框、室内灯墙、寺院香烟和湖岸芦苇背景，并随主题过场柔和衔接
- 古门排在盘珠子之后，使用深木门板、青色石板路和红底贴纸横批“傅家”
- “灯具开关”使用悬挂灯与墙面翘板开关；每次手动按动都会在灯亮 / 灯暗间切换，并同步改变整屏明暗
- “上柱香”使用带铜绿、兽耳和三足结构的青铜香炉与燃香取代木槌；每柱香都会准确落入灰面，赛博反拍会自动添香
- “青团捣捣”使用艾草叶垫底的绿色软糯青团，命中时会明显横向摊开、压扁、拉丝，并把青团碎屑喷溅到四周
- “盘珠子”使用 14 颗密排大木珠组成独立悬浮闭环，整体逆时针旋转 90° 呈竖向构图，并以约 12 秒一圈持续无缝旋转；珠串运动不改变光源，所有珠子的高光固定来自左上，暗面与投影固定落向右下
- 用户照片会在浏览器中居中裁切为 512×512 圆形敲击主题；上传按钮明确提示“仅存于本地使用，永不上传”
- 手动操作、“赛博对敲”反拍协作、“赛博助盘”反拍加速与“赛博代放”
- 内置 `For Luck` 背景音乐，视觉节拍、手动判定和自动操作共用 128 BPM 音乐时间轴
- 敲击与转珠每 2 拍落点一次（937.5ms），放生每 4 拍落点一次（1875ms）
- 主体背后的粉色四边形以四角和四边直接提示四分音符；敲击主题显示“敲 / 对”，盘珠显示“转 / 助”，操作拍会明显外冲、放大、扭转并爆出环形射线
- 首次手动操作统一显示 `START` 并正常积攒，但不计入连击；音乐起播后以实际媒体时间重新校准下一次 MISS
- `PERFECT / GOOD / COOL` 节拍判定与连击
- 判定标签使用独立前景 Canvas 和动态安全区，不会再被顶栏、记录卡或页脚盖住
- MISS 等待窗增加约 15% 移动端容错
- 整轮累计允许 2 次 MISS：第 1 次显示“1 / 2 · 还有一次”并继续，第 2 次才进入抽签
- 连续 3 次 `PERFECT` 触发 10 秒特殊时刻；高对比前景横幅固定在屏幕最上方、可覆盖顶栏 UI，并按当前主题自动邀请赛博鼓槌或赛博助盘反拍助力
- 开启“赛博对敲”后，不锈钢赛博鼓槌会立即从屏幕上方伸入；顶部固定轴让槌头在木鱼左上侧待机，再沿圆弧摆向木鱼左侧，命中点比此前上移 20px
- 用户敲正拍，赛博鼓槌在相邻反拍增加 1 功德；赛博奖励计入本轮签文数字，但不增加用户连击，也不会清除 MISS
- 歌曲播放时，半透明模式色覆盖剩余背景，其边界像沙漏一样从屏幕顶部向下退场，并带有落砂流和颗粒
- 第 2 次大号 `MISS` 反馈后延迟 500ms 揭签
- 七档加权赛博签：大吉 15%、中吉 28%、小吉 26%、小凶 18%、中凶 8%、大凶 4%、神佑 1%
- “神佑”特殊签包含跳动狗图与“财神赐福 · 真心可逢”跑马灯
- 大吉使用 16 枚持续跳动的 💰 / 🌸 背景庆祝；其他普通签继续保持 8 枚，避免所有结果都过度拥挤
- 收下或化解签文会立即停止并回卷音乐，下一次操作从歌曲开头重新启拍
- 带漫画外轮廓的粉色放生主拍箭头与 🫳 入水按钮
- 放生舞台以墨迹晕染逐字写出“阳澄湖”；`PERFECT` 判定会放生一只浑身长着辣椒与火焰的火辣蟹，其他判定继续放鱼，鱼蟹都会以更快的冲刺—放缓节奏非匀速游向远处
- Canvas 2D 动画、Web Audio 合成音效与响应式布局
- 除模式与设置控件外，可轻触可见页面任意位置，或上下滑动屏幕执行当前动作
- 使用动态可见视口适配微信内置浏览器的顶部 / 底部栏变化与短窗口
- 部署到 Cloudflare Pages 后，个人功德与放生记录按服务端 HMAC-SHA256 IP 哈希延续，原始 IP 不落库
- 全球功德与全球放生来自 Cloudflare D1 的真实累计数据，不再使用前端演示数字
- 离线操作使用幂等事件队列暂存在当前设备，恢复网络后自动补传
- 主题选择、圆形照片和背景音乐设置保存在当前设备
- 背景音乐按钮只控制 BGM；木鱼、木珠、灯具开关、上香、放生和抽签仪式音效始终播放
- 木鱼撞击整体增益提高；吉签使用明亮上扬和声，凶签使用低沉下行音调
- 键盘操作、减少动态和高对比模式支持

## 本地运行

项目不需要构建或安装依赖。在项目目录启动任意静态文件服务器：

```bash
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。

## 操作

- 点击、轻触可见页面任意非控件区域，或上下滑动屏幕：按当前主题敲击、转珠、按动开关、上香或放生
- 开局前左右滑动：循环切换八款主题
- 顶栏主题轮盘 `←` / `→`：切换上一款 / 下一款主题
- 选择“敲张照片”后使用“上传照片 / 换一张照片”：在本机裁切并更换圆形敲击照片，照片永不上传
- `Space`：执行当前模式的操作
- 聚焦木鱼或放生舞台时 `←` / `→`：切换主题
- 赛博对敲 / 赛博助盘：进入协作待命；由用户第一敲或第一次转珠启动歌曲并负责正拍，赛博角色随后协助反拍
- 赛博稳光：用户在正拍切换灯光明暗，赛博角色在反拍提供稳光奖励，不会自动闪烁整屏
- 赛博添香：用户在正拍上香，赛博角色在反拍自动向香炉添香
- 赛博代放：开启放生模式的全自动操作
- BGM 图标：只开启或静音背景音乐；木槌、木珠、开关、上香、水声与抽签音效不受影响

浏览器会在第一次敲击、放生、开启赛博代放或重新开启背景音乐时开始播放 BGM。单独开启“赛博对敲”只进入待命，不会抢先播歌；第一次手动敲击仍是启拍，不判断好坏，随后用户跟正拍、赛博鼓槌跟反拍。收下或化解签文后，音乐停止并回到开头，下一次操作重新显示 `START`。

## 音乐与节拍

- 曲目：`For Luck`
- 艺术家：`imfandesign`
- 速度：128 BPM
- 强拍偏移：约 435ms
- 首次手动操作会用音乐实际起播时间反推首个强拍，让下一次操作拍拥有完整拍长与 15% 宽容，不会在拍点到来前提前 MISS
- 木鱼对敲与盘珠加速锁定相邻四分音符反拍，赛博命中与用户正拍相隔约 468.75ms；放生自动操作继续锁定每四拍一次的主拍
- 八主题轮换使用同一媒体时间轴累计四分音符，每 16 拍触发一次，不依赖会漂移的固定定时器
- 协作与自动操作都会在每次动作前重新核对音乐相位，避免浏览器定时器和音频启动延迟造成漂拍
- 收签或化解时清除播放与页面恢复状态并回卷到 0 秒，确保新一轮从歌曲开头开始

## 真实计数与隐私

- 生产入口：<https://for-luck.pages.dev/>。同源 `/api/ritual` 已部署到 Cloudflare Pages，全球功德和全球放生写入亚太区 D1。
- Cloudflare Pages Function 从 `CF-Connecting-IP` 读取公网 IP，只在内存中使用 `IP_HASH_SECRET` 做 HMAC-SHA256；D1 仅保存不可逆哈希，不保存原始 IP。
- 同一公网 IP 会共用个人记录；更换网络、VPN、运营商出口或 IPv6 地址后，个人记录可能变化。
- 每次敲击 / 放生携带唯一事件 ID，D1 事务保证重试不会重复累计。
- 照片只在浏览器中裁切并写入本地存储，不会发送到 `/api/ritual`。
- GitHub Pages 只能展示前端，不能执行 `/api/ritual`；真实入口必须使用上方 Cloudflare Pages 地址。
- 静态预览不会请求第三方定位服务；生产环境可通过 `data-location-endpoint` 接入同源 IP 地理接口，有结果时自动显示所在地，无结果时默认显示“苏州”。

## Cloudflare Pages + D1 部署

当前 `wrangler.toml` 已绑定正式 `for-luck` D1。仅在迁移到新的 Cloudflare 账号时重新创建数据库：

   ```bash
   npx wrangler d1 create for-luck
   ```

1. 把新返回的 `database_id` 写入 `wrangler.toml`，再初始化数据库：

   ```bash
   npx wrangler d1 execute for-luck --remote --file=schema.sql
   ```

2. 为 IP 哈希设置至少 16 字符的随机密钥：

   ```bash
   openssl rand -hex 32 | npx wrangler pages secret put IP_HASH_SECRET --project-name for-luck
   ```

   上线后不要轮换该密钥，否则已有 IP 哈希会失去连续性。

3. 部署当前目录：

   ```bash
   npx wrangler pages deploy . --project-name for-luck
   ```
