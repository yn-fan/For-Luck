# 佛了 · For Luck

一个移动优先的原创网页仪式玩具：跟随节拍敲木鱼、积攒功德，或向无边海中放生鱼儿。

## 功能

- 木鱼与放生双模式
- 手动操作与“赛博代敲 / 赛博代放”
- 内置 `For Luck` 背景音乐，视觉节拍、手动判定和自动操作共用 128 BPM 音乐时间轴
- 木鱼每 2 拍落点一次（937.5ms），放生每 4 拍落点一次（1875ms）
- 原创“环身拍签”围绕木鱼或入水点逐个提示四分音符：操作位显示“敲 / 放”，准备位只显示圆点，不再使用无解释的数字
- 首次手动操作统一显示 `START` 并正常积攒，但不计入连击；音乐起播后以实际媒体时间重新校准下一次 MISS
- `PERFECT / GOOD / COOL` 节拍判定与连击
- MISS 等待窗增加约 15% 移动端容错
- 连续 3 次 `PERFECT` 触发 10 秒特殊时刻
- 大号 `MISS` 反馈后延迟 500ms 揭签
- 七档加权赛博签：大吉 15%、中吉 28%、小吉 26%、小凶 18%、中凶 8%、大凶 4%、神佑 1%
- “神佑”特殊签包含跳动狗图与“财神赐福 · 真心可逢”跑马灯
- 大吉使用持续跳动的 💰 / 🌸 背景庆祝；签文卡采用原创黑白红高对比漫画拼贴
- 带漫画外轮廓的粉色放生主拍箭头与 🫳 入水按钮
- Canvas 2D 动画、Web Audio 合成音效与响应式布局
- 除模式与设置控件外，可轻触可见页面任意位置执行当前动作
- 使用动态可见视口适配微信内置浏览器的顶部 / 底部栏变化与短窗口
- 功德、放生和声音设置保存在当前设备
- 键盘操作、减少动态和高对比模式支持

## 本地运行

项目不需要构建或安装依赖。在项目目录启动任意静态文件服务器：

```bash
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。

## 操作

- 点击或轻触可见页面任意非控件区域：敲木鱼 / 放生
- `Space`：执行当前模式的操作
- `←` / `→`：切换木鱼与放生
- 赛博代敲 / 赛博代放：开启当前模式的自动操作
- 声音图标：同时开启或关闭背景音乐与合成音效

浏览器会在第一次敲击、放生、开启自动操作或重新开启声音时开始播放背景音乐。首次手动操作是启拍，不判断好坏；随后跟随主体四周的拍签继续。

## 音乐与节拍

- 曲目：`For Luck`
- 艺术家：`imfandesign`
- 速度：128 BPM
- 强拍偏移：约 435ms
- 首次手动操作会用音乐实际起播时间反推首个强拍，让下一次操作拍拥有完整拍长与 15% 宽容，不会在拍点到来前提前 MISS
- 自动操作在每次动作前重新核对音乐相位，避免浏览器定时器和音频启动延迟造成漂拍

## 技术

- Vanilla HTML、CSS、JavaScript
- Canvas 2D
- Web Audio API
- HTML Audio
- Visual Viewport API
- Local Storage
- 无第三方运行时依赖

## 数据说明

- 个人功德与放生记录仅保存在当前浏览器。
- 全球功德与全球放生数字为交互演示数据。
- 静态预览不会请求第三方定位服务；生产环境可通过 `data-location-endpoint` 接入同源 IP 地理接口，有结果时自动显示所在地，无结果时默认显示“苏州”。
