# 不要在苏州园区亲嘴 · 佛了 for luck

一个移动优先的原创网页小游戏：在一首歌内找出东方之门周围正在亲吻的情侣，消耗功德抓啵，获得搞笑称号并分享战报；功德不足时，可进入八款仪式主题继续积攒。

## 默认玩法：不要在苏州园区亲嘴

- “佛了 / FOR LOVE”与“佛了 / FOR LUCK”品牌卡根据抓啵、积德模式正确切换；P5/Memphis 风“享用功德 / 积攒功德”双模式 Tab 作为品牌卡的附着式下轨，共用黑色外壳和双层彩色背板。游戏开始后整条下轨及其装饰层从布局和辅助功能树中移除，干净让位给大号 `PERFECT` 与次级 `MISS` 成绩 HUD。
- 抓啵页左上显示“佛了 / FOR LOVE”与“他不是不爱你，他是要赶去上海的高铁”；“不要在苏州园区亲嘴 / 小红书亲嘴文学de音游”移到东方之门上方，锐角 P5 `START 抓啵` 固定在屏幕中央。
- `START` 前，东方之门的河岸、广场与露台有 11 个按稳定时间轴行走的小人：附近两人会相遇、短暂亲吻后分开，三位路人会偶尔跳一小段舞。预备人群不生成目标、圆环、电光、分数或可点击语义，并始终绕开中央标题与 `START` 安全区；按下 `START` 会清空命中区域并切换到正式局。减少动态时只显示安静的静态人群。
- 点击 `START` 后先在东方之门上空绽放大烟花，再启动用户提供的《苏州园区亲嘴》；抓啵节奏切换为 132 BPM、首拍偏移约 358ms，前 2 秒依次显示无圆环的赛车式像素大字 `3 / 2 / 1 / GO!`。
- 开局只有 1 对情侣；人群随歌曲进度增长到最多 20 对，使用稳定但不规则的两岸、步道和楼层露台点位，不再整齐排队。
- 东方之门前保留短广场，再以更宽、上缘更靠近建筑的青粉霓虹河流贯穿左右视口；部分远景情侣站在楼层露台上，人物大小随景深变化。
- 人物使用稳定映射的短发、波波头、长发、马尾、丸子头和卷发，不会随帧随机闪烁。
- 亲吻目标严格跟随 132 BPM：每四拍为一轮，只出现一对；前两拍亲吻、后两拍隐藏，命中后本轮不补出新目标。
- 每 32 拍触发一次持续 4 拍的 `DANCE BREAK`：所有人物以前景手掌明确遮住脸和鼻子，另一手横摆并配合双腿 juke bounce；每一拍严格出现两个垂直弹跳峰值，期间暂停亲吻目标，结束后恢复随机抓啵。
- 亲吻期间同时出现更大的姿态变化、原创漫画心形、发光实线环、四向刻度和引导线，不只依赖颜色；远景目标的心形同步放大，外围虚线椭圆已移除。
- 点中目标后亲吻立即结束，东方之门发射带亮芯和外发光的漫画电光，被击中人物整体发光，本局抓啵数 +1，并触发镜头冲击；命中时偶尔浮现像素字“我要在你们的爱河里嘘嘘”。
- 河中偶尔掠过只有鸡头轮廓、带微亮眼睛和水纹遮挡的神秘影子；`Lv999 窑鸡王` 直接使用描边像素字，不再使用名牌背景。河面还会偶尔有桨板玩家横向经过。
- “赛博代抓”改为下方功德记录卡内的紧凑次级能力，不再悬浮遮挡东方之门、河流或情侣；按钮清楚显示 10 功德成本与本局剩余次数。每局最多 3 次，仅在情侣亲吻时生效，不会直接抓住目标，而会用双探照灯冰冻当前情侣 3 秒。启动时天空放烟花并密集飘落桃花，用户仍需手动点击完成抓啵。
- 每次成功抓啵从可用功德中扣除最多 10 点。至少 1 点即可开局；余额不足时降到 0，但仍可继续完成本局，下一局必须先积德。
- 一局优先读取音乐真实时长，歌曲结束即结算；媒体时长不可用时使用 60.072 秒备用计时。
- 结果页是高对比 P5/Memphis 手机抓啵签：顶部迷你东方之门会周期发射漫画闪光，人群随之散开；其下仅显示城市标签、超大搞笑称号和紧邻的 `PERFECT / MISS` 行。城市信息不会包含网络地址。
- “抓到亲嘴 X 对”缩成贴在纸张右上缘的小徽章；“继续游戏”是唯一主 CTA，下一称号、本机最佳与功德条在其后降级呈现。`babblelab.cn` 二维码成为贴在抓啵签底边、略微旋转并带硬阴影的实体贴纸。
- 结果场景只在对话框打开时运行；减少动态时停在静态最终姿势，Windows 强制颜色模式下隐藏装饰画布，不影响内容与键盘操作。
- 右上 P5 风 `MERIT HP` 贯穿两种模式，只显示可用功德、上一次称号与血条；积德或消费时出现 `+1 功德`、`−10 功德` 或“功德见底”反馈。

## 积攒功德

抓啵结果页或顶部“积攒功德”Tab 可进入副模式。该模式保留原有八款主题，东方之门不再出现在主题轮盘中：

1. 玄木共鸣：袈裟福田衣背景与像素字“爱在西园寺”
2. 青团捣捣：艾草青团压扁、拉丝与飞溅，背后显示像素字“不时不食”
3. 盘珠子：14 颗竖向闭环念珠，判定越准旋转越快
4. 开门啊我知道你在家！：门头“天香里45号”与黄色黄包车
5. 敲张照片：本地裁切圆形照片，永不上传
6. 灯具开关：翘板开关同步改变整页明暗
7. 上柱香：无题字青铜香炉与赛博添香
8. 放生：整页湖水、“阳澄湖水怪”与 `Lv999 窑鸡王`

八款主题继续共用 128 BPM 时间轴、`PERFECT / COOL / GOOD` 判定、赛博协作、3 次连续 `PERFECT` 特殊时刻、两次 `MISS` 容错和七档赛博签。放生仍可能出现视觉吞鱼，但已经获得的放生记录不会回退。

## 操作

- 抓啵开局：点击 P5 `START`、按 `Space` / `Enter`，或上下滑动；该用户手势会启动始终开启的抓啵 BGM，再等待 `3 / 2 / 1 / GO!` 结束。
- 抓啵进行中：指针点中正在亲吻的情侣；键盘、舞台按钮与上下滑动会直接锁定当前目标。
- 赛博代抓：在下方功德记录卡找到该按钮；目标出现时按按钮、Tab 聚焦后按 `Space` / `Enter`，消耗 10 功德并冻结目标 3 秒；本局最多使用 3 次。
- 积攒功德：轻触可见页面非控件区域、按 `Space` / `Enter`，或上下滑动执行当前动作。
- 积攒功德开局前：左右滑动或使用舞台左右方向键切换主题；顶部主题选择器已移除。
- 音乐按钮仅在积攒功德模式显示并控制该模式的 BGM；进入享用功德模式会强制恢复抓啵 BGM，抓啵界面不提供静音控件。浏览器仍需在 `START` 用户手势后才会播放。木槌、木珠、开关、上香、电光、水声和抽签音效始终保留。

## 功德与数据

- D1 中的个人功德表示累计获得功德；抓啵不会产生新的功德入账事件。
- 100 点赠送余额只存在前端，不污染 D1 累计；抓啵消费保存在当前设备，可用功德为“100 + 累计获得功德 - 当前设备累计消费”，最低为 0。
- 全球功德和全球放生不再显示，也不参与产品主循环。
- 同源 `/api/location` 只向页面返回 Cloudflare 请求上下文中的城市、地区和国家信息，禁止缓存、不写入数据库；结果签只显示城市标签，例如“📍苏州”。
- 同源 `/api/ritual` 继续为个人累计获得功德与放生提供匿名连续性。
- `/api/ritual` 仅在内存中把网络地址转换为 HMAC-SHA256 匿名标识；D1 不保存原始地址，页面、可访问名称和结果描述也不会呈现该地址。
- 每次积德或放生使用唯一事件 ID 幂等入账；断网事件暂存在当前设备，恢复网络后重试。
- 更换网络、VPN 或运营商出口后，个人累计记录可能变化。

## 无障碍

- 所有操作使用原生按钮或链接，并提供可访问名称和至少 24×24 CSS px 的触控目标。
- 结果页使用模态对话框语义，先聚焦成绩标题，支持 Tab / Shift+Tab、Esc 关闭与焦点恢复。
- 动态成绩通过 `aria-describedby` 完整说明；倒计时与短暂亲吻目标拥有对应可访问名称，异步目标状态使用持久 live region。
- 支持 `prefers-reduced-motion` 与 Windows 强制颜色模式；减少动态时关闭镜头位移、齐舞跳动和反馈飞出，只保留静态姿态与文字状态。
- 视觉目标同时使用姿态、文字、形状与线条，不只依赖颜色。

## 本地运行

项目不需要构建或安装依赖。在当前目录启动任意静态文件服务器：

```bash
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。

## Cloudflare Pages + D1 部署

`wrangler.toml` 已绑定正式 `for-luck` D1。仅在迁移到新的 Cloudflare 账号时重新创建数据库：

```bash
npx wrangler d1 create for-luck
npx wrangler d1 execute for-luck --remote --file=schema.sql
openssl rand -hex 32 | npx wrangler pages secret put IP_HASH_SECRET --project-name for-luck
```

不要随意轮换 `IP_HASH_SECRET`，否则已有匿名 IP 哈希会失去连续性。

部署当前目录：

```bash
npx wrangler pages deploy . --project-name for-luck
```

正式项目入口为 <https://for-luck.pages.dev/>；分享二维码使用 <https://babblelab.cn/>。
