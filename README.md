# 佛了 · For Luck

一个移动优先的原创网页仪式玩具：跟随节拍敲木鱼、积攒功德，或向无边海中放生鱼儿。

## 功能

- 木鱼与放生双模式
- 手动操作与“赛博代敲 / 赛博代放”
- `PERFECT / GOOD / COOL` 节拍判定与连击
- 连续 3 次 `PERFECT` 触发 10 秒特殊时刻
- 大号 `MISS` 反馈后延迟 500ms 揭签
- 随机六档吉凶签、中英双语关键词、不裁切的黄黑品牌贴纸与米黄半调内容卡
- 带漫画外轮廓的粉色放生主拍箭头与 🫳 入水按钮
- Canvas 2D 动画、Web Audio 合成音效与响应式布局
- 功德、放生和声音设置保存在当前设备
- 键盘操作、减少动态和高对比模式支持

## 本地运行

项目不需要构建或安装依赖。在项目目录启动任意静态文件服务器：

```bash
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。

## 操作

- 点击或轻触画面：敲木鱼 / 放生
- `Space`：执行当前模式的操作
- `←` / `→`：切换木鱼与放生
- 赛博代敲 / 赛博代放：开启当前模式的自动操作
- 声音：开启或关闭合成音效

## 技术

- Vanilla HTML、CSS、JavaScript
- Canvas 2D
- Web Audio API
- Local Storage
- 无第三方运行时依赖

## 数据说明

- 个人功德与放生记录仅保存在当前浏览器。
- 全球功德与全球放生数字为交互演示数据。
- 静态预览不会请求第三方定位服务；生产环境可通过 `data-location-endpoint` 接入同源 IP 地理接口，有结果时自动显示所在地，无结果时默认显示“苏州”。
